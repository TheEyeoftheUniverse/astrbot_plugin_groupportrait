# 安装修复轮探测证据（2026-09-12）

打回理由：主开发者在 AstrBot 安装失败——「未在 GitHub 仓库根目录找到 metadata.yaml 或 metadata.yml」。

## 结论

**metadata.yaml 与仓库结构完全正常，唯一根因 = GitHub 仓库是私有的。**
AstrBot 对 github.com 插件仓库一律走「匿名 archive 通道」（raw 元数据预检 + codeload zip 下载，无凭据支持）；私有仓库下匿名请求全部 404，安装器把 404 误报成「未找到 metadata.yaml」。

## 探测矩阵（目标仓库 TheEyeoftheUniverse/astrbot_plugin_groupportrait，默认分支 main）

| 通道 | 匿名（模拟主开发者） | 认证（gh token / keychain） |
|---|---|---|
| `api.github.com/repos/...` | 403 rate-limit / 元数据不可见 | 200，`isPrivate: true` |
| `raw.githubusercontent.com/.../main/metadata.yaml` | **404** | 200（metadata.yaml 在） |
| `github.com/.../archive/refs/heads/main.zip`（codeload） | **404** | 200（zipball 1,516,545 B） |
| `git clone --depth 1`（GIT_TERMINAL_PROMPT=0 无凭据助手） | **`fatal: unable to get password from user`** | 成功 |

## 真实安装器复现（AstrBot v4.28.0，venv 发行版本体）

`repro_install_error.py` → `repro_真实安装器_报错原文.log`：

```
GET raw.githubusercontent.com/TheEyeoftheUniverse/astrbot_plugin_groupportrait/main/metadata.yaml → 404
GET raw.githubusercontent.com/TheEyeoftheUniverse/astrbot_plugin_groupportrait/main/metadata.yml  → 404
ValueError: 未在仓库根目录找到 metadata.yaml 或 metadata.yml。
```

与主开发者报错同源（其原话多「GitHub」二字，属版本/转述差异，失败类相同）。

对照组：同一安装器装公开仓库 `Soulter/helloworld`（master 分支）→ raw 200 → 预检通过，
证明代码路径本身无恙、差异只在仓库可见性。
（旁证：api.github.com 匿名限流时安装器猜 `main` 分支，master 公开插件也会报同款错——本仓库默认分支恰是 main，不受此影响。）
